# Business Operating System Command Center

A public-safe executive operating-system demo that consolidates cross-functional KPIs, initiatives, risks, decisions, and automated work queues into one management view.

## Demonstrates
- executive KPI command center
- cross-functional initiative tracking
- risk / escalation management
- decision log
- automated work queues
- management briefing generation
- finance + operations + commercial visibility

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
